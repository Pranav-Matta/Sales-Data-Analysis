# 📊 Power BI Project 1: Sales Data Analysis

## 📌 Project Overview

This project is an end-to-end **Sales Data Analysis solution developed using Microsoft Power BI**.

The project focuses on data preparation, transformation, data modeling, DAX calculations, filtering, and interactive visualization to generate meaningful insights from sales data.

It demonstrates practical implementation of important **Power BI data modeling concepts**, including Primary Keys, Foreign Keys, Cardinality, Relationships, and Star Schema.

---

## 🎯 Objectives

- Prepare and transform sales data for analysis
- Perform data profiling and data cleaning
- Build a structured Power BI data model
- Understand and implement Primary Key and Foreign Key relationships
- Configure relationship cardinality
- Design a Star Schema data model
- Create DAX measures and calculations
- Analyze sales, quantity, and profit performance
- Identify Top 5 and Bottom 5 performing products
- Analyze sales trends over time
- Implement filters and slicers
- Configure visual interactions
- Customize filter behavior for dimension table slicers

---

## 📚 Project Scope

### 1. Business Requirements

Understanding the business requirements and identifying the analytical needs of the sales report.

### 2. Loading Data to Power BI Desktop

Importing the required sales data into Power BI Desktop.

### 3. Data Profiling & Data Transformations

Performing data profiling, data cleaning, and transformations using Power Query to prepare the data for analysis.

### 4. Primary & Foreign Keys

Understanding Primary Keys and Foreign Keys and using them to establish relationships between tables.

### 5. Cardinality

Understanding and implementing relationship cardinality between tables in the Power BI data model.

### 6. Star Schema

Designing a Star Schema using fact and dimension tables to create an efficient analytical data model.

### 7. Data Model Overview

Building and reviewing the complete data model and validating table relationships.

### 8. Filters in Power BI

Working with different types of filters available in the Power BI Filters pane.

### 9. Top & Bottom 5 Product Analysis

Analyzing the Top 5 and Bottom 5 products based on:

- Sales
- Quantity
- Profit

### 10. Sales Trends Over Time

Analyzing sales performance over time to identify trends and changes in business performance.

### 11. DAX Calculations

Creating DAX measures and calculations to fulfill specific business requirements and generate meaningful insights.

### 12. Visual Interactions

Configuring and editing interactions between Power BI visuals to control how selections affect other visuals.

### 13. Additional Business Requirements

Implementing additional analytical and reporting requirements to enhance the report.

### 14. Filter Behavior for Dimension Slicers

Customizing filter behavior for dimension table slicers to provide better control over the report's interactive experience.
